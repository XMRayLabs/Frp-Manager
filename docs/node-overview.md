# 概览统计

概览显示四个卡片：在线客户端（在线/总量）、在线服务端（在线/总量）、待处理客户端、待处理服务端。

- 在线表示节点与面板建立了管理连接，不保证每条隧道都正常。同一个在线节点也可以需要处理。
- 总量与节点列表使用相同的可见范围和临时节点规则，内部子客户端不单独计数。
- 待处理涵盖尚未完成配置、配置校验失败、离线或运行异常，以及节点版本低于当前面板版本。原因数量可以重叠，待处理总数按物理节点去重。
- 客户端只有基础连接配置、尚无代理或访问者时，视为未完成配置。一个客户端连接多个服务端时，其中任一配置或运行检查失败都会计入待处理。
- 主动暂停的客户端/代理不因暂停而计入运行异常；配置问题和升级需求仍会计入。
- 代理运行状态使用后台批量检测；首次加载及配置刚修改后，运行异常数量会在随后刷新时更新。概览每 15 秒刷新，后台运行检查并发有上限。
- 服务端使用兼容旧协议的内核健康探测：旧节点仍可连接，但只有更新后的服务端能报告内核未启动或已退出。旧节点仍可通过离线、静态配置检查和版本差异被标记。
- 升级需求以当前面板版本为基准；未知/开发版本不推断为需要升级。统计不主动访问外部发布站点。

接口：`GET /api/v1/platform/overview`，沿用登录鉴权和节点可见范围，只返回数量，不返回密钥或配置内容。`/platform/baseinfo` 保留原有兼容接口。

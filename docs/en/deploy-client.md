# Deploy A Client

Clients run managed FRPC, Worker, and WireGuard configurations.

## Get Connection Details

1. Sign in to Master.
2. Open **Clients** and create a Client.
3. Click the Client ID to open the install guide.
4. Verify that the API and RPC endpoints are reachable from the target host.
5. Copy the command for that operating system.

Prefer HTTPS/WSS:

```text
API URL: https://manager.example.com
RPC URL: wss://manager.example.com
```

## Linux systemd

```bash
curl -fSL https://raw.githubusercontent.com/XMRayLabs/Frp-Manager/main/install.sh \
  | bash -s -- --version latest client \
  -i CLIENT_ID -s CLIENT_SECRET \
  --api-url https://manager.example.com \
  --rpc-url wss://manager.example.com
```

The installer downloads directly from GitHub Releases and verifies `SHA256SUMS-core.txt`.

```bash
systemctl status frpp
journalctl -u frpp -f
```

## Windows

Desktop users should install the latest
[Windows GUI](https://github.com/XMRayLabs/Frp-Manager/releases/latest/download/frp-manager-client-windows-x64.exe).
Select **Install / Apply** and approve the UAC prompt. The GUI installs the core and its administrator-only
configuration under `%ProgramFiles%\frp-manager`.
The dashboard install guide also provides a PowerShell command for a headless Windows service.

## macOS

Desktop users can install the Intel or Apple Silicon GUI DMG. For unattended use, download the full binary and run
the command generated by the dashboard. For an unsigned GUI build, use
**System Settings → Privacy & Security → Open Anyway** after the first launch attempt.

## Android

ARM64 devices can install the latest
[Android APK](https://github.com/XMRayLabs/Frp-Manager/releases/latest/download/frp-manager-client-android.apk).
Create or import a profile and select **Install / Apply**. The bundled core runs in a foreground service with a
persistent Android notification. **Stop** also disables restart after reboot; **Start** or **Install / Apply**
enables it again.

## Existing Binary

```bash
./frp-manager client \
  -i CLIENT_ID -s CLIENT_SECRET \
  --api-url https://manager.example.com \
  --rpc-url wss://manager.example.com
```

Never place a Client secret in public logs, tickets, or source control.

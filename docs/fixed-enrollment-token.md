# 固定自动接入令牌

自动接入客户端、服务端分别使用当前账号的固定令牌，首次打开接入窗口时生成并保存在面板数据库中。令牌长期有效，刷新页面和重启面板不会重新生成。不同账号和节点角色使用不同令牌。

“令牌设置（通常无需修改）”中可以更换令牌，必须在确认弹窗中再次确认。更换立即撤销对应角色的旧固定令牌；其他账号、另一种角色和已经保存独立身份的设备不受影响。多个窗口同时更换时，过时的确认请求会被拒绝。

固定令牌只能调用对应角色的注册和身份读取接口，不能调用面板管理或令牌更换接口。管理接口仍使用正常登录权限，服务端令牌管理要求管理员身份。

升级面板时自动创建 enrollment_tokens 表，无需修改 Docker 目录或节点命令格式。旧版签发的 24 小时 JWT 接入令牌仍按原期限过期；固定令牌更换不会撤销这些历史 JWT。新复制的命令使用固定令牌。

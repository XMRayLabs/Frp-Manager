# 批量创建用户与首次改密

在用户管理的“批量创建用户”中输入起始用户名、起始邮箱和数量。默认示例为 ig01、ig01@xmray.de、30，生成 ig01–ig30 和对应邮箱。编号保留前导零，超出位数自然递增；每批最多 100 个。

每个用户为当前管理员租户下的普通用户，初始密码为各自邮箱，数据库仅保存密码散列。创建前预览范围，用户名或邮箱冲突时整批拒绝；插入失败时整批回滚，不覆盖现有账号。

新用户首次登录进入修改密码页面，需要提供当前密码并设置符合现有密码规则、不同于邮箱的新密码。改密成功前，后端阻止其他业务 API（仅允许读取自身信息、改密状态和提交首次改密）。退出登录仍可使用。成功后清除首次改密标志，初始密码不能再登录。

已有用户默认不启用首次改密要求。用户列表显示“首次登录待改密”。新增数据库字段通过启动迁移自动创建。

旧版节点的 main 版本（不区分大小写、忽略首尾空格）现在始终提示需要升级，概览待处理统计使用相同规则。
